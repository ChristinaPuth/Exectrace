## 3. What the page does

`app.py`, one file, about 125 lines, plus the theme file:

- **Look:** a plain light business theme (`.streamlit/config.toml`) and,
  above the chat, one line with the company, its domain, the collection date
  and the run status.
- **Sidebar:** a company selector (the companies in the fixtures) and the
  four sample questions as a hint.
- **Chat:** each company keeps its own history for the browser session. An
  answer goes through the M5 agent unchanged, including the sources appended
  from the queried rows.
- **Panel under each answer**, "SQL and source rows": every query that ran,
  its rows as a table, or why it failed or returned nothing, and whether the
  answer came from the cache.
- **Incomplete data:** if the company's run status is not `complete`, a
  warning above the chat says the answers are based on partial data.
- **No key:** an error that says how to add one; no chat box.
- **Model failure:** the agent's error message is shown as an error, not as
  an answer.

## 4. Issues met during M6

| # | What happened | Cause | Resolution |
|---|---|---|---|
| 1 | `st.dataframe` failed to load | This machine's Windows application control policy blocks pyarrow's compiled library | The rows are shown as a Markdown table, which needs no pyarrow. The policy was not changed or worked around |
| 2 | `uv run streamlit run app.py` was refused | The same policy blocks the `streamlit.exe` launcher | Run it as `uv run python -m streamlit run app.py`. That works everywhere, so it is the documented command |

## 5. Decisions made during M6 that the spec did not fix

Please confirm or change these in MT-6.6.

1. **Markdown tables instead of `st.dataframe`** (issue 1). The tables cannot
   be sorted, and cells longer than 160 characters are shortened.
2. **History is per company and per browser session.** It is not saved, and
   reloading the page clears it.
3. **The sample questions in the sidebar are a hint only.** They cannot be
   clicked. That would be a little more code and is not in the spec.
